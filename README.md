# ☕ Cafeteria Aroma

Site institucional desenvolvido em **HTML, CSS e JavaScript** para representar uma cafeteria moderna, aconchegante e elegante. O projeto apresenta informações sobre a cafeteria, cardápio, produtos, galeria de imagens, depoimentos e formas de contato.

---

## 📖 Sobre o Projeto

A **Cafeteria Aroma** foi criada como um projeto de desenvolvimento web com foco em praticar a construção de páginas utilizando apenas tecnologias front-end.

O objetivo é oferecer uma interface agradável e intuitiva para apresentar os principais serviços e produtos da cafeteria.

---

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

---

## ▶️ Como Executar

1. Faça o download do projeto.
2. Abra a pasta no Visual Studio Code.
3. Instale a extensão **Live Server**.
4. Clique com o botão direito em **index.html**.
5. Selecione **Open with Live Server**.
